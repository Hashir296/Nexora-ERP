# Nexora ERP (MERN)

Core platform + plugin architecture. Light theme. Local MongoDB. Google Gemini AI optional.

## Quick start

```bash
cd D:\eps\server
npm install
npm run seed
npm run dev

cd D:\eps\client
npm install
npm run dev
```

- API: http://localhost:5000
- App: http://localhost:5173
